# AI Usage

AI tools were used as a development assistant during this assessment.

## Areas Where AI Assisted

AI was used to help:

- Break the assessment into incremental implementation steps
- Review product requirements and scope
- Discuss database modeling choices
- Generate initial implementation suggestions
- Suggest API and test cases
- Review edge cases
- Discuss performance considerations
- Structure engineering documentation

## Verification Approach

AI-generated suggestions were not treated as automatically correct.

Changes were reviewed and validated through:

- Database migrations
- Manual API testing
- Automated Rails tests
- React production builds
- Manual end-to-end testing

Implementation decisions were adjusted when runtime behavior or tests
identified issues.

## Examples

Examples of prompts used during development included:

- Design a salary management application for 10,000 employees using Rails
  and React.
- How should salary history be modeled without overwriting previous salary
  information?
- How should employee search and pagination be implemented efficiently?
- What automated tests should cover employee and salary APIs?
- How should multi-currency salary analytics avoid misleading totals?

## Engineering Responsibility

AI was used to accelerate implementation and exploration. Final design,
testing, verification, and submission decisions remained the responsibility
of the developer.
